# Join Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create `join.html` — a shareable landing page that smart-detects Supabase auth state and shows the right experience to each visitor.

**Architecture:** Single self-contained HTML file at the repo root. Loads `data.js` and `auth.js` (same as `index.html`). Auth.js already injects all its own CSS via a `<style>` element, so `join.html` only needs page/card layout styles. Auth state is detected on `DOMContentLoaded` via `_getClient().auth.getSession()` + a profile fetch, then the `#auth-modal-inner` div (the same div auth.js targets) is populated with the correct state.

**Tech Stack:** Vanilla HTML/CSS/JS, Supabase JS client (via `data.js`), existing `HeroesAuth` object (via `auth.js`). No new dependencies.

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Join Heroes Senior Softball</title>
  <style>
    *, *::before, *::after { box-sizing: border-box; margin: 0; padding: 0; }

    body {
      min-height: 100vh;
      background: #111;
      display: flex;
      flex-direction: column;
      align-items: center;
      justify-content: center;
      font-family: Arial, Helvetica, sans-serif;
      padding: 24px 16px;
    }

    .join-card {
      background: #fff;
      border-radius: 16px;
      width: 100%;
      max-width: 460px;
      overflow: hidden;
      box-shadow: 0 8px 40px rgba(0,0,0,.5);
    }

    /* auth.js writes into this div — padding replaces the modal's internal spacing */
    #auth-modal-inner { padding: 28px 28px 20px; }

    .join-loading {
      text-align: center;
      padding: 48px 0;
      color: #aaa;
      font-size: 14px;
    }
    .join-spinner {
      width: 32px;
      height: 32px;
      border: 3px solid #e5e7eb;
      border-top-color: #C8102E;
      border-radius: 50%;
      animation: spin .7s linear infinite;
      margin: 0 auto 12px;
    }
    @keyframes spin { to { transform: rotate(360deg); } }

    .join-footer {
      text-align: center;
      padding: 14px;
      background: #f8f8f8;
      border-top: 1px solid #e5e7eb;
      font-size: 12px;
      color: #aaa;
    }
    .join-footer a { color: #C8102E; text-decoration: none; }
    .join-footer a:hover { text-decoration: underline; }
  </style>
</head>
<body>

<div class="join-card">
  <div id="auth-modal-inner">
    <div class="join-loading">
      <div class="join-spinner"></div>
      Loading…
    </div>
  </div>
  <div class="join-footer">
    <a href="index.html">heroesseniorsoftball.com</a>
  </div>
</div>

<script src="assets/js/data.js"></script>
<script src="assets/js/auth.js"></script>
<script>
  (async () => {
    const sb = _getClient();
    const { data: { session } } = await sb.auth.getSession();

    if (!session) {
      // New visitor — show registration form (auth.js handles form + submission + admin notification)
      HeroesAuth._renderRegisterForm();
      return;
    }

    const { data: profile } = await sb
      .from('profiles')
      .select('display_name, approved')
      .eq('id', session.user.id)
      .single();

    const firstName = (profile?.display_name || '').trim().split(/\s+/)[0] || 'there';
    const inner = document.getElementById('auth-modal-inner');

    if (!profile?.approved) {
      inner.innerHTML = `
        <div class="auth-approval-state">
          <div class="auth-approval-icon">⏳</div>
          <h2 class="auth-approval-title">You're on the list, ${firstName}!</h2>
          <p class="auth-approval-msg">Your account is pending approval. A team admin will review it shortly — hang tight!</p>
          <a href="index.html" class="auth-submit-btn">Back to Heroes</a>
        </div>`;
    } else {
      inner.innerHTML = `
        <div class="auth-approval-state">
          <div class="auth-approval-icon">⚾</div>
          <h2 class="auth-approval-title">Welcome back, ${firstName}!</h2>
          <p class="auth-approval-msg">You're all set — head to the player portal.</p>
          <a href="index.html" class="auth-submit-btn">Go to My Portal →</a>
          <button class="auth-secondary-btn" onclick="(async()=>{await _getClient().auth.signOut();location.reload();})()">Not you? Sign out</button>
        </div>`;
    }
  })();
</script>

</body>
</html>
```
